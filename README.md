# 🌐 CCNA Enterprise Labs

Topologias e laboratórios de redes Cisco para certificação CCNA.

## Labs

| Tópico | Descrição |
|---|---|
| VLAN | Segmentação de rede com VLANs |
| STP | Spanning Tree Protocol |
| EtherChannel | Agregação de links |
| OSPF | Roteamento dinâmico |
| ACL | Listas de controle de acesso |
| NAT | Network Address Translation |
| DHCP | Configuração de servidor DHCP |
| IPv6 | Endereçamento IPv6 |

## Ferramentas
- `packet-tracer/` → Labs no Cisco Packet Tracer (.pkt)
- `gns3/` → Topologias no GNS3
